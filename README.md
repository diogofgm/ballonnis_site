# Ballonni's Pizzas Artesanais

Site Jekyll pronto para hospedar no GitHub Pages.

## Status do Site

- **Página principal**: Em construção - mostra mensagem de "Site em Construção"
- **Página beta**: Versão completa do site acessível em `/beta.html`

## Como usar

1. Coloque este repositório no GitHub.
2. Ative o GitHub Pages na branch principal (`main` ou `master`) e use a pasta `/` como fonte.
3. O GitHub Pages processará o site com Jekyll automaticamente.

## Arquivos principais

- `_config.yml` — configuração do Jekyll.
- `_layouts/default.html` — layout principal do site.
- `index.html` — página de construção temporária.
- `beta.html` — versão completa do site.
- `assets/css/styles.css` — estilos responsivos.
- `assets/images/ballonnis-logo.jpg` — imagem de branding.
- `_data/menu.yml` — dados do menu editáveis.
- `_includes/` — componentes reutilizáveis (header, navigation, footer).
